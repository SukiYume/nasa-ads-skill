## Operating boundaries

The active host agent reads sources and authors scientific summaries. The CLI retains an explicit pending state until authorship completes. Structural validation checks identity, coverage declarations, and integrity; scientific conclusions still depend on faithful reading and source verification.

The Web interface supports browsing and downloads on the local computer. Classification, notes, and summaries are maintained through the agent or CLI. Official BibTeX can be fetched once and reused offline. Metadata-generated entries retain a visible provenance label.

The database uses schema 3; the full-article digest remains schema 2. Existing libraries use explicit `init` with an automatic pre-migration backup. New default captures are local writes. Remote ADS operations remain read-only except separately requested ADS Library mutations.

Validation artifacts under `.validation/` include API responses, authored test summaries, the isolated library, unittest output, and installation state snapshots. They are excluded from version control. These changes are ready in the project working tree; publishing and updating the user's active installation are separate actions.
